## ชั้นของการแปล — อะไรแปลได้แค่ไหน

คําว่า "รองรับการแปล" ของโปรเจกต์นี้มี 4 ชั้น ไม่เท่ากัน ต้องแยกให้ชัด

| ชั้น | แปลอะไร | ไฟล์ต้นทาง | ใครเห็น |
|---|---|---|---|
| **1. UI หลัก** | ข้อความทั้งหน้าจอ DSH (เมนู ปุ่ม สถานะ ฯลฯ) | `lib/client.js` (`thDicts`) | ทุกคนที่เลือกภาษาไทย |
| **2. UI กวนตีน** | ชุดเดียวกับชั้น 1 แต่พูดจากวน | `lib/client.js` (`thRoastDicts`) + `tools/roast-source/` | คนที่เลือก `ไทย (กวนตีน)` |
| **3. การ์ดปลั๊กอิน** | ชื่อ + คําอธิบายในหน้ารายการปลั๊กอิน | `plugin-locales/cards/th.txt` | เห็นในหน้าปลั๊กอิน |
| **4. UI ของปลั๊กอินเอง** | ข้อความข้างในหน้าตั้งค่าของปลั๊กอินบางตัว | `plugin-locales/ui/*.json` | เห็นเฉพาะปลั๊กอินนั้น |

**ข้อจํากัดที่ต้องรู้**: ปลั๊กอิน 45 ตัวมี **ชื่อ+คําอธิบายไทยครบทุกตัว (ชั้น 3)** แต่ **ชั้น 4 มีแค่ 9 ตัว** เพราะปลั๊กอินที่เหลือไม่มีคําแปลของตัวเองให้ต่อ ต้องแก้ไฟล์ของปลั๊กอินนั้นตรง ๆ ตามสคริปต์ `tools/install-plugin-ui.mjs`

## ยังไม่ได้ทํา

- **ชั้น 4 ของปลั๊กอินที่เหลือ 35 ตัว** — ต้องแก้ไฟล์ UI ของปลั๊กอินนั้นทีละตัว (`tools/install-plugin-ui.mjs`) และจะถูกเขียนทับเมื่ออัปเดตปลั๊กอิน
- **ทั่วทั้งเครื่อง** — ตัวเลขนี้คือโปรไฟล์ `web` เท่านั้น ถ้ามีโปรไฟล์อื่นต้องตรวจแยก
- **การ์ด 229 รายการ** ในคลังมากกว่าปลั๊กอินที่ติดตั้ง (45) เพราะคลังครอบคลุมปลั๊กอินทั้งระบบ รวมตัวที่ยังไม่ได้ติดตั้ง

## วิธีตรวจซ้ําเอง

```bash
cd ~/.dsh/tmp/dsh-thai-locale-edit
node tools/install-plugin-cards.mjs   # เขียน locale/th.json ของการ์ดลงเครื่อง
node tools/install-plugin-ui.mjs      # แปะคําแปล UI ของ 9 ปลั๊กอิน
```

หลังรันต้อง **รีสตาร์ท DSH** ชื่อปลั๊กอินจึงจะอ่านใหม่
