# AGENTS.md — guide for AI coding agents

This file is written for AI coding agents (Claude Code, Codex, Cursor, and similar tools). Humans should read README.md first.

## What this project is

`dsh-thai-locale` is a DSH (DeepSeek Harness) plugin that adds a Thai UI language (`th`) to DSH Web. It is a translation pack, not an application. It has no runtime dependencies and makes no network calls.

## Layout

| Path | Role |
|---|---|
| `package.json` | Plugin manifest. The `dsh` block points to the patch file and sets the client platform to `web`. `files` limits what gets published to npm. |
| `cordis.patch.yml` | Host patch that inserts this plugin's row into the composed configuration. Do not change the id without updating the manifest. |
| `lib/index.js` | Host half. Intentionally empty (`apply()` does nothing). |
| `lib/client.js` | Client half and the single source of truth for translations. Runtime-loaded by DSH. |
| `locale/en.json`, `locale/th.json` | Plugin name and description shown in DSH's plugin list. |
| `icon.svg` | Plugin icon: the Thai flag, generated by `tools/generate-icon.py` (Python 3, optional). |
| `NOTICE` | Attribution for material taken from DeepSeek Harness (MIT). Keep it when you change the license text. |
| `tools/check-translations.mjs` | Dependency-free checker for corruption patterns. Run with `npm run check`. |
| `TRANSLATION_REVIEW.md` | Heuristic list of strings that may still contain typos. |

## How the client code works

`lib/client.js` is one wrapper around a dictionary:

```js
window.__ModuleLoader__.load({ id: "dsh-thai-locale", factory: () => { /* ... */ } });
```

Inside the factory:
- `const thDicts = { "<namespace>": { "<key>": "<Thai text>" } }` holds the translations (about 4,600 keys across about 75 namespaces). This is the part you edit.
- `apply(ctx)` uses `ctx.locale` (`runtime`) to call `addLanguage({ id: "th", label: "ไทย", fallback: "zh" })` (guarded in try/catch), then `runtime.register(ns, { th: dict })` for each namespace, then `runtime.setLocale("th")`. Each call is wrapped in try/catch on purpose: one failure must not disable the whole plugin.
- `exports.inject = ["locale"]` and `exports.name = "dsh-thai-locale"` are required by DSH.

Fallback order at runtime is th → zh → en, so a missing Thai key just shows Chinese or English.

## Rules for editing translations

1. Only edit values inside `thDicts`. Never rename keys, reorder namespaces, or touch the wrapper unless the task is about the wrapper.
2. Keep every `{placeholder}` exactly as in the original value, including its name and braces. For example `{count}`, `{value}`, `{toolName}`.
3. Do not put CJK (Chinese or Japanese) characters in Thai values.
4. Do not use Lao characters (U+0E80–U+0EFF) in Thai text. They look like Thai letters but are different code points.
5. Use NFC-normalized Unicode. Do not write doubled combining marks.
6. Brand names, product names, command names (for example `/plan`, `compact`, `Bash`), protocol terms (`API Key`, `Base URL`, `TTFT`), and tool names stay in English.
7. Prefer Thai for plain English words in UI labels. Examples already applied: feedback → ข้อเสนอแนะ, skill → สกิล, Route ID → รหัสเส้นทาง, Call ID → รหัสการเรียก.
8. Do not add network calls, `eval`, `localStorage`, `sessionStorage`, or other browser storage to `lib/client.js`.
9. Do not add a dependency. The project deliberately has none.

## Verify before you finish

```bash
node --check lib/client.js     # syntax
npm run check                  # translation checker; must report Errors: 0
```

Also confirm the key count is unchanged (4601 at the time of writing) unless you intentionally added or removed keys.

## Known limitations

- The repository has no English source file, so the full key coverage of DSH cannot be verified here. Do not restore the claim "100%" without a source to check against.
- Some strings are still suspected of typos. They are listed in `TRANSLATION_REVIEW.md`. Fix them in context. Many entries are correct.
- Only DSH Web is declared as supported. DSH Desktop is untested.
- The install command in the README (`dsh plugin --profile web add dsh-thai-locale`) has not been confirmed against DSH's official docs.
- Namespaces such as `dsh-android-mobile.*` and `dsh-android-market` are included. They may not be used on the web platform.

## Icon

The icon is the Thai flag drawn as a waving flag on a rounded tile. To change it, edit `tools/generate-icon.py` and run `python3 tools/generate-icon.py`. Do not add the DeepSeek logo or other third-party trademarks to the icon.

## Versioning

Follow the maintainer's convention: small fixes and corrections bump the last number (1.0.0 → 1.0.1). Only bigger updates or many new features bump the middle number. Very small changes may use a fourth part (1.0.1.1).
