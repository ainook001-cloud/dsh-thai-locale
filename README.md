# DSH ภาษาไทย (dsh-thai-locale)

ปลั๊กอินภาษาไทยสำหรับ **DeepSeek Harness (DSH)** แปลข้อความหน้าจอของ DSH เป็นภาษาไทย และตั้งภาษาเป็นไทยให้เมื่อติดตั้งเสร็จ

## ฟีเจอร์

- แปลข้อความ UI เป็นไทย 4,601 ข้อความ ใน 75 หมวด (namespace)
- ลงทะเบียนภาษา `th` ในรายการภาษาของ DSH
- สลับเป็นภาษาไทยให้หลังติดตั้ง (เปลี่ยนกลับได้ที่ตั้งค่า)
- คีย์ที่ยังไม่มีคําแปลไทยจะแสดงจีนหรืออังกฤษแทน (th → zh → en)
- ไม่ต้องติดตั้ง dependency เพิ่มเติม โค้ดไม่เรียกอินเทอร์เน็ต และไม่บันทึกข้อมูลลงเบราว์เซอร์

## 📋 ข้อกำหนด

| รายการ | รายละเอียด |
|---|---|
| แพลตฟอร์ม | DSH Web — **ทดสอบแล้ว** |
| DSH Desktop | **ยังไม่ได้ทดสอบติดตั้งจริง** — คาดว่าใช้ได้เพราะ Desktop เป็น Electron ที่รัน Web UI ชุดเดียวกัน |
| เวอร์ชัน DSH ที่ทดสอบแล้ว | `0.2.1-rc.2` |
| Node.js | ไม่จำเป็นสำหรับการใช้งาน ใช้เฉพาะตอนตรวจคำแปล |

> `package.json` ประกาศ `dsh.client.platform: "web"` เพราะ client bundle ของ DSH
> ทั้ง Web และ Desktop ใช้ค่าเดียวกันนี้ (Web GUI เป็นตัวเดียวที่โหลด client plugin)
> ค่านี้ไม่ได้แปลว่า "ห้ามใช้บน Desktop" แต่ก็ยังไม่ได้ยืนยันด้วยการติดตั้งจริง

## 🚀 วิธีติดตั้ง

1. เปิดเทอร์มินัลบนเครื่องที่ติดตั้ง DSH และมีคําสั่ง `dsh` ใน PATH
   (คําสั่งนี้เป็นของ CLI ถ้าไม่มี `dsh` ต้องติดตั้ง DSH ก่อน)
2. รันคำสั่งต่อไปนี้

   ```bash
   dsh plugin --profile web add dsh-thai-locale
   ```

3. รอจนติดตั้งเสร็จ แล้วเปิด DSH Web ใหม่

## 📖 วิธีใช้งาน

1. หลังติดตั้ง ภาษาจะเปลี่ยนเป็นไทยอัตโนมัติ
2. ถ้ายังเป็นภาษาอื่น ให้ไปที่ **การตั้งค่า → ภาษา** แล้วเลือก **ไทย**
3. ถ้าพบข้อความที่แปลไม่ถูกต้อง หรือยังเป็นภาษาอังกฤษ ดูวิธีแจ้งในไฟล์ [CONTRIBUTING.md](CONTRIBUTING.md)

## 🔄 เปลี่ยนกลับเป็นภาษาอื่น

ไปที่ **การตั้งค่า → ภาษา** แล้วเลือกภาษาที่ต้องการ หรือถอนปลั๊กอินด้วยคำสั่งถอนของ DSH

## 🌐 สถานะคำแปล

- แก้อักษรเพี้ยนที่พบชัดเจนแล้ว เช่น อักษรลาวที่หน้าตาคล้ายภาษาไทย เครื่องหมายวรรณยุกต์ซ้ำ และคำที่สะกดผิดบางคำ
- แปลคำภาษาอังกฤษที่ควรเป็นไทยไปแล้วบางส่วน เช่น feedback → ข้อเสนอแนะ, skill → สกิล
- ยังมีข้อความประมาณ 178 รายการที่อาจมีคำผิด ดูรายการได้ที่ [TRANSLATION_REVIEW.md](TRANSLATION_REVIEW.md)
- โปรเจกต์นี้ไม่มีไฟล์ภาษาอังกฤษต้นฉบับ จึงยืนยันว่าแปลครบ 100% ไม่ได้ ถ้าต้องการช่วยตรวจทาน ยินดีรับ Pull Request

## 🛠 สำหรับผู้พัฒนา

- ไฟล์คำแปลหลักคือ `lib/client.js` ในส่วน `const thDicts = { ... }` จัดกลุ่มตามชื่อ namespace เช่น `"approval": { "waiting": "รอการอนุมัติ" }`
- คงชื่อคีย์และตัวแปรอย่าง `{tokens}` ไว้เหมือนเดิม และห้ามมีอักษรจีนในคำแปล
- ตรวจคำแปลก่อนส่งงานทุกครั้ง

```bash
node --check lib/client.js
node tools/check-translations.mjs   # หรือ npm run check ถ้ามี npm
```

- ถ้าใช้ AI agent ให้อ่าน [AGENTS.md](AGENTS.md) ก่อนแก้ไฟล์

## 🧪 การทดสอบ

```bash

node --test tests/*.test.mjs        # รันโค้ดจริงใน sandbox
```

- ตัวตรวจอักษร: 4,601 คีย์ ต้องได้ข้อผิดพลาด 0

## 🧩 ชื่อปลั๊กอินทดลองฉบับไทย

DSH แสดงชื่อและคำอธิบายปลั๊กอินทดลองจากไฟล์ `locale/<รหัสภาษา>.json` ในโฟลเดอร์ของแพ็กเกจนั้น
แพ็กเกจที่แถมมากับแอปมีแค่ `en.json` กับ `zh.json` จึงตกไปใช้ภาษาจีนเมื่อตั้งภาษาเป็นไทย

โปรเจกต์นี้เก็บไฟล์ `th.json` ของปลั๊กอินทดลอง **22 ตัว** ไว้ใน `plugin-locales/experimental/`

```bash
node tools/install-plugin-locales.mjs
```

### สคริปต์เขียนอะไรบ้าง

| ทำ | ไม่ทำ |
|---|---|
| เขียน/อัปเดต `locale/th.json` ของ 22 แพ็กเกจ | แตะ `en.json`, `zh.json` |
| เขียนทับ `th.json` เดิมถ้ามีอยู่ (เนื้อหาจากรีโปนี้ ไม่ merge) | แตะไฟล์อื่นของแอป |
| ข้ามแพ็กเกจที่ไม่มี `locale/en.json` | เพิ่มโฟลเดอร์ให้แพ็กเกจที่ไม่มีอยู่ |

⚠️ ถ้าเคยแก้ `th.json` ไว้เอง ให้ **สำรองก่อนรัน** เพราะสคริปต์จะเขียนทับ
รันซ้ำได้ผลเท่าเดิม (idempotent)

หลังติดตั้งต้อง **รีสตาร์ท DSH** เพราะชื่อปลั๊กอินถูกอ่านตอนบูต
ไฟล์อยู่ในโฟลเดอร์เอนจิน — อัปเดตแอปหรือใช้ Safe Mode แล้วจะหาย ให้รันสคริปต์ซ้ำ

ชุดคำแปลสำหรับ **ตลาดปลั๊กอิน DSH** (แคตตาล็อกปลั๊กอิน) แยกไว้ใน `market/`

|---|---|

| คำอธิบายปลั๊กอิน | **57 รายการ** (agi 45, wsl 12) |
| Node.js | ไม่จําเป็นสําหรับการใช้งาน ใช้เฉพาะตอนตรวจคําแปล |

รายละเอียดวิธีเพิ่มคำแปลทีละหมวดและทะเบียนคำศัพท์อยู่ที่ [market/README.md](market/README.md)

## ⚠️ ข้อจำกัดที่ทราบ

- **ทดสอบบน DSH Web เป็นหลัก** — DSH Desktop ยังไม่ได้ทดสอบติดตั้งจริง
- บางข้อความอาจยังเป็นภาษาอังกฤษหรือจีนเพราะระบบ fallback
- **ยังไม่มี automated UI test** — ตรวจคำแปลได้เฉพาะไวยากรณ์และรูปแบบอักษร (ตัวตรวจใน `tools/`)

- คําอธิบายปลั๊กอินในตลาดแปลแล้ว **57 รายการ** จากแคตตาล็อกทั้งหมด 5,324 รายการ (ตัวเลข 5,324 มาจาก index.json ของ awesome-dsh-plugin ณ วันที่ดึงข้อมูล — รีโปนี้ไม่เก็บไฟล์นั้น)
