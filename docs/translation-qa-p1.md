# ตรวจคําแปลไทย รอบ P1 (178 รายการ)

ไฟล์นี้เป็นผลตรวจรายการทั้งหมดใน `TRANSLATION_REVIEW.md` (178 คีย์) พร้อมคําตัดสินทีละรายการ
ข้อความที่ต้องแก้ถูกแก้ใน `lib/client.js` บล็อก `const thDicts` แล้ว (คงชื่อคีย์และ `{placeholder}` ไว้เหมือนเดิม)

## วิธีตรวจ

1. ดึงค่าจริงจาก `lib/client.js` ด้วยการ parse บล็อก `thDicts` (ได้ 4601 คีย์) แล้วเทียบกับค่าใน `TRANSLATION_REVIEW.md`
   — ผลคือ **ค่าในรายการทั้ง 178 ตรงกับค่าจริงในไฟล์ทุกตัว** (ผลต่าง 8 จุดที่เห็นเป็นแค่การ escape `\"` ในไฟล์รายการ)
2. สแกนระดับอักขระทั้ง 178 รายการ: อักษรลาว (U+0E80–U+0EFF), อักษร CJK, เครื่องหมายประกอบซ้ํา, วรรณยุกต์ซ้อน,
   วรรณยุกต์มาก่อนสระ, เครื่องหมายลอยหลังช่องว่าง, พยางค์เริ่มด้วยเครื่องหมาย — **ไม่พบข้อผิดพลาดระดับอักขระเลย**
3. เทียบกับต้นทางจริงของปลั๊กอิน (zh/en) ที่ติดตั้งในเครื่อง เช่น
   `engine/node_modules/@deepseek-ai/dsh-client-ui-*` (`dsh-client-ui-conversation`, `-plugin-manager`, `-schedule`,
   `-trajectory`, `-user-questions`, `-agent-preset`), `~/.dsh/profiles/web/node_modules/dsh-any-background`,
   `dsh-plugin-thinking-api` และ `~/.dsh/mobile-ui/dsh-android-mobile` (ไฟล์ `.th-bak` คือต้นฉบับภาษาจีนก่อนแพตช์)
4. ตรวจแล้วแก้ 8 รายการ, ที่เหลือ 170 รายการอ่านรู้เรื่องและตรงบริบท

หมายเหตุความน่าเชื่อถือ: รอบนี้ตรวจโดยผู้ช่วย AI ภาษาไทย ไม่ใช่คน — ถ้าต้องการ sign-off จากเจ้าของภาษา
ควรมีคนอ่านซ้ําอีกรอบ โดยเฉพาะกลุ่มที่อ่านจากความเข้าใจอย่างเดียว (ไม่ได้เทียบต้นทาง) ซึ่งระบุไว้ในคอลัมน์หมายเหตุ
