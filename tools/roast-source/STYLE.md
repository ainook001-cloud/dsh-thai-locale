# คู่มือโทนภาษาไทยกวนตีน (th-roast)

ใช้กับทุกไฟล์ใน `tools/roast-source/<namespace>.json` คำตอบเดียว: ข้อความไทยที่กวนขึ้น แต่ยังบอกความหมายเดิม

## น้ำเสียง

ประชดเบา ๆ แบบเพื่อนที่สนิท ไม่ด่า ไม่ดูถูก ไม่ตัดพ้อ และไม่เล่นมุกจนความหมายหาย
ตัวอย่างที่ใช้ได้

- `กำลังโหลด…` → `เดี๋ยว รอก่อน อะไรมันจะโหลด`
- `ลบ` → `จัดไป เชิญหายากันหมดเลย`
- `ลองใหม่` → `กดซ้ำแล้วมันจะดีขึ้นป่าววะ`

ตัวอย่างที่ใช้ไม่ได้

- ใส่คำหยาบหรือคำดูถูกผู้ใช้
- เล่นมุกจนอ่านไม่ออกว่าปุ่มนี้ทำอะไร
- ใส่อีโมจิ

## กฎที่ตรวจด้วยเครื่องได้

1. **ห้ามแตะ `{placeholder}`** ต้องมีครบและสะกดเหมือนเดิมทุกตัว
2. **ห้ามแตะชื่อแบรนด์ ชื่อเครื่องมือ ชื่อคำสั่ง** เช่น `DSH`, `GitHub`, `pnpm`, `Bash`, `/plan`, `compact`, `API Key`, `TTFT`, `JSON`, `ZIP`
3. **ห้ามแตะตัวเลข วันที่ และค่า config** ตัวเลขทุกตัวต้องอยู่ครบ
4. **ความยาว** ไม่เกิน 1.6 เท่าของข้อความไทยเดิม และไม่เกิน 120 ตัวอักษร
5. **ห้ามเติมคำท้ายซ้ำ** คำอย่าง `นะ`, `ครับ`, `สิ`, `เลย` เติมได้ครั้งเดียว และห้ามใช้สองตัวติดกัน (`นะ ครับ`, `ครับ ครับ`)
6. **ป้ายสั้น (ไทยเดิมสั้นกว่า 8 ตัวอักษร) ให้เลือกคำใหม่ ไม่ใช่เติมคำท้าย** เช่น
   - ดี: `สถานะ` → `สถานะมันเป็นงี้`
   - ไม่ดี: `สถานะ` → `สถานะ ครับ`
7. **ข้อความโครงสร้างให้คงรูป** ถ้าค่าเป็นสัญลักษณ์ล้วน ตัวเลขล้วน คำเชื่อมโดด ๆ (`" หรือ "`) หรือชื่อหน่วย ให้คงเดิม แล้วระบบจะใช้ภาษาไทยธรรมดาแทนเอง
8. **ห้ามมีอักษรจีน/ญี่ปุ่นหรืออักษรลาว** และต้องเป็น Unicode รูป NFC
9. **ห้ามใส่เครื่องหมายอัญประกาศหรือแบ็กสแลช** ในค่า ให้เขียนเป็นข้อความธรรมดา

## ไฟล์ทำงานอย่างไร

`tools/roast-source/<namespace>.json` เก็บเฉพาะค่าภาษาไทยกวน ไม่เก็บคีย์อธิบาย

```json
{
  "ok": "ตกลง ๆ เอาตามนั้น",
  "cancel": "เลิก ๆ ไปเถอะ"
}
```

คีย์ต้องมีอยู่ใน `thDicts` ของ `lib/client.js` ทั้งหมด ถ้าคีย์ไม่ตรง ตัวสร้างจะฟ้องและไม่ยอมเขียนไฟล์
ค่าที่ไม่ต้องกวน (เช่น สัญลักษณ์ล้วน) ให้เขียนค่าภาษาไทยเดิมลงไปตรง ๆ ได้ ตัวตรวจจะรายงานว่าเป็น `SAME` ระดับ warn เท่านั้น

หลังเขียนเสร็จให้รัน

```bash
node tools/build-roast.mjs   # ประกอบเป็นบล็อก thRoastDicts ใน lib/client.js
node tools/check-roast.mjs   # ตรวจคุณภาพ
```

ห้ามแก้บล็อก `thRoastDicts` ใน `lib/client.js` ด้วยมือ เพราะรอบสร้างถัดไปจะทับ
