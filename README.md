# DSH ภาษาไทย (dsh-thai-locale)

ปลั๊กอินนี้เพิ่มภาษาไทยให้หน้าจอ DeepSeek Harness (DSH) เมื่อติดตั้งแล้วจะเปลี่ยนภาษาเป็นไทยให้ทันที ถ้าคำไหนยังไม่มีคำแปล ระบบจะใช้ภาษาอังกฤษแทน (`th → en`)

นอกจากไทยธรรมดา ยังมีโหมด **ไทยกวนตีน** (`ไทย (กวนตีน)`) ให้เลือกในตัวเลือกภาษา — คำแปลชุดเดิมแต่จิกกัดเบา ๆ แบบเพื่อน คีย์ที่ยังไม่ได้เขียนชุดกวนจะแสดงภาษาไทยธรรมดาแทน (`th-roast → th → en`)

**สถานะชุดกวนตีน ณ ตอนนี้: 8 จาก 75 หมวด (661 คีย์) เขียนใหม่ 438 คีย์** ที่เหลือ 3,940 คีย์ยังใช้ภาษาไทยธรรมดา แปลกวนเก็บเป็นไฟล์แยกใน `tools/roast-source/` หมวดละไฟล์ สร้างด้วย `npm run roast:build` แล้วตรวจด้วย `npm run roast:check` — ยังไม่ได้ตรวจด้วยตาทุกคีย์

## มีอะไรแปลไว้บ้าง

- ข้อความ UI ของ DSH 4,601 รายการ ใน 75 หมวด
- ชื่อและคำอธิบายของปลั๊กอิน 196 แพ็กเกจ
- ข้อความในหน้าตั้งค่าของปลั๊กอิน 9 ตัว รวม 625 รายการ
- พจนานุกรมของ `dsh-our-free-model` 873 คีย์ และ `dsh-amd-free-model` 188 คีย์
- ตลาดปลั๊กอิน: ชื่อตลาด 23 หมวด และคำอธิบายปลั๊กอิน 57 รายการ

ไม่ต้องลง dependency เพิ่ม โค้ดของปลั๊กอินไม่เรียกอินเทอร์เน็ตและไม่เก็บข้อมูลในเบราว์เซอร์

## ข้อกำหนด

| รายการ | สถานะ |
|---|---|
| DSH Web | ทดสอบแล้วกับ `0.2.1-rc.2` |
| DSH Desktop | ยังไม่ได้ทดสอบติดตั้งจริง; คาดว่าจะใช้ได้เพราะรัน Web UI ชุดเดียวกัน |
| Node.js | ไม่ต้องใช้ตอนติดตั้งหรือใช้งาน; ใช้ตรวจคำแปลและรันทดสอบเท่านั้น |

ใน `package.json` ระบุ `dsh.client.platform: "web"` เพราะ Web GUI เป็นตัวโหลด client plugin ส่วน Desktop ยังไม่ได้ลองติดตั้ง จึงยังยืนยันจากการใช้งานจริงไม่ได้

## ติดตั้ง

ต้องมี DSH CLI (`dsh`) อยู่ใน PATH แล้วรัน:

```bash
dsh plugin --profile web add dsh-thai-locale
```

เมื่อติดตั้งเสร็จ ให้เปิด DSH Web ใหม่ หากยังไม่เปลี่ยนภาษา ไปที่ การตั้งค่า → ภาษา แล้วเลือก **ไทย** หรือ **ไทย (กวนตีน)**

## เปลี่ยนภาษา หรือถอนปลั๊กอิน

เปลี่ยนภาษาได้ที่ การตั้งค่า → ภาษา หากต้องการถอนปลั๊กอิน ให้ใช้คำสั่งถอนของ DSH

## สถานะคำแปลและงานที่ยังเหลือ

ตัวตรวจเคยตั้งข้อสงสัยไว้ 178 รายการ รายการเหล่านี้ไม่ได้แปลว่าผิดทั้งหมด—หลายคำถูกต้องเมื่อดูตามบริบท ดูรายการและสถานะล่าสุดได้ใน [TRANSLATION_REVIEW.md](TRANSLATION_REVIEW.md) และ [TRANSLATION_STATUS.md](TRANSLATION_STATUS.md)

รีโปนี้ไม่มีไฟล์ข้อความต้นฉบับภาษาอังกฤษครบชุด จึงเทียบความครอบคลุมของทุกคีย์ไม่ได้ และยืนยันไม่ได้ว่าแปลครบทั้งหมด หากเจอคำผิดหรือข้อความที่ยังไม่แปล ส่งตัวอย่างหน้าจอหรือชื่อคีย์มาได้ ดูวิธีส่งไว้ใน [CONTRIBUTING.md](CONTRIBUTING.md)

## สำหรับคนแก้คำแปล

คำแปล UI หลักอยู่ใน `lib/client.js` ภายใน `const thDicts` แยกตาม namespace เช่น:

```js
"approval": { "waiting": "รอการอนุมัติ" }
```

ชุดกวนตีน **อย่าแก้ใน `lib/client.js`** ให้แก้ที่ `tools/roast-source/<namespace>.json` หมวดละไฟล์ (ใส่เฉพาะคีย์ที่เขียนกวน คีย์ที่ไม่ใส่จะ fallback ไปไทยธรรมดา) แล้วรัน

```bash
node tools/build-roast.mjs   # เขียนบล็อก thRoastDicts ใน lib/client.js ใหม่
node tools/check-roast.mjs   # ตรวจ placeholder / อักษรต้องห้าม / คำท้ายซ้ำ / ความยาว
```

`tools/roast-source/_ref/` เก็บค่าภาษาไทยเดิมของแต่ละหมวดไว้เทียบ สร้างใหม่ได้ด้วย `node tools/build-roast.mjs --ref` และไม่ถูก commit โทนการเขียนอยู่ใน [tools/roast-source/STYLE.md](tools/roast-source/STYLE.md)

ตอนแก้ให้คงชื่อคีย์และ placeholder เช่น `{tokens}` ไว้ ห้ามใส่อักษรจีนหรือลาวในข้อความไทย ใช้ Unicode แบบ NFC และอย่าแปลชื่อแบรนด์ ชื่อคำสั่ง หรือชื่อเครื่องมือ อ่าน [AGENTS.md](AGENTS.md) ก่อนใช้ AI agent ช่วยแก้ไฟล์

ตรวจ syntax และคำแปลด้วยคำสั่งเหล่านี้:

```bash
node --check lib/client.js
node tools/check-translations.mjs
node --test tests/*.test.mjs
```

ตัวตรวจเช็ก 4,601 คีย์ว่ามีอักษรต้องห้ามหรือรูปแบบที่น่าสงสัยหรือไม่ ส่วนชุดทดสอบรัน `lib/client.js` ใน sandbox และตรวจการลงทะเบียน 75 namespace, fallback, `setLocale` กับ `dispose` รวม 6 ข้อ ยังไม่มี automated UI test ที่เปิด DSH แล้วตรวจข้อความบนหน้าจอจริง รายละเอียดอยู่ใน [docs/testing.md](docs/testing.md)

## โครงสร้างโปรเจกต์

```
dsh-thai-locale/
├── package.json                 ข้อมูลแพ็กเกจและการตั้งค่า DSH
├── cordis.patch.yml             แพตช์เพิ่มปลั๊กอินใน DSH
├── lib/
│   ├── index.js                 ส่วน host; ไม่มีงานอื่นนอกจากลงทะเบียนปลั๊กอิน
│   └── client.js                คำแปล UI หลัก
├── locale/                      ชื่อและคำอธิบายปลั๊กอินภาษาอังกฤษ/ไทย
├── market/                      คำแปลตลาดปลั๊กอิน
├── plugin-locales/              คำแปลการ์ดและหน้าตั้งค่าปลั๊กอิน
├── tests/                       ชุดทดสอบ client plugin
├── docs/                        วิธีทดสอบและข้อความประกาศ
├── tools/                       ตัวตรวจและสคริปต์ติดตั้งคำแปล
├── TRANSLATION_REVIEW.md         รายการที่ควรตรวจคำแปล
├── TRANSLATION_STATUS.md         สถานะการตรวจรายการที่สงสัย
├── VERSIONING.md                 กฎการตั้งเลขเวอร์ชัน
├── AGENTS.md                     คู่มือสำหรับ AI agent
├── CONTRIBUTING.md               วิธีแจ้งปัญหาและส่งคำแปล
├── LICENSE                       สัญญาอนุญาต
└── NOTICE                        รายละเอียดที่มาของงาน
```

## คำแปลการ์ดปลั๊กอิน

DSH แสดงชื่อและคำอธิบายปลั๊กอินจากไฟล์ `locale/<รหัสภาษา>.json` ในแต่ละแพ็กเกจ ชุดที่มากับแอปมีภาษาอังกฤษกับจีน แต่ไม่มีไทย สคริปต์นี้เติมไฟล์ไทยให้แพ็กเกจที่อยู่ในรายการของรีโป:

```bash
node tools/install-plugin-cards.mjs
```

สคริปต์เขียนเฉพาะ `locale/th.json` และเขียนทับไฟล์เดิมทั้งไฟล์ ไม่ได้รวมกับเนื้อหาเดิม ส่วน `en.json`, `zh.json` และไฟล์อื่นจะไม่ถูกแตะ

## คำแปลหน้าตั้งค่าปลั๊กอิน

บางปลั๊กอินเขียนข้อความภาษาจีนไว้ในโค้ดตรง ๆ แทนที่จะใช้ระบบภาษา คำแปลของ 9 ปลั๊กอินนี้อยู่ใน `plugin-locales/ui/`:

| ปลั๊กอิน | ข้อความ |
|---|---:|
| `dsh-any-background` | 196 |
| `dsh-opencode-patch` | 116 |
| `dsh-boot-guard` | 70 |
| `dsh-ops` | 52 |
| `dsh-token-saver` | 47 |
| `dsh-plugin-save-token` | 45 |
| `dsh-plugin-guard` | 38 |
| `dsh-plugin-thinking-api` | 38 |
| `dsh-compaction-threshold` | 23 |
| รวม | 625 |

ติดตั้งคำแปลด้วย:

```bash
node tools/install-plugin-ui.mjs
```

สคริปต์แก้ไฟล์ client ของปลั๊กอินโดยแทนข้อความเดิม และเก็บสำเนาเดิมเป็น `<ไฟล์>.th-bak` ก่อน หากอัปเดตปลั๊กอิน ไฟล์ที่แก้อาจถูกเขียนทับด้วยเวอร์ชันใหม่ ให้รันสคริปต์นี้อีกครั้ง

## พจนานุกรมของปลั๊กอิน

`dsh-our-free-model` และ `dsh-amd-free-model` มีระบบภาษาของตัวเอง เพิ่มคำแปลไทยไว้แล้วในไฟล์ใต้ `plugin-locales/dict/`

## คำแปลตลาดปลั๊กอิน

ไฟล์คำแปลตลาดอยู่ใน `market/` ตอนนี้มีชื่อและคำอธิบายตลาด ชื่อ 23 หมวด และคำอธิบายปลั๊กอิน 57 รายการ (agi 45, wsl 12) รายการที่เหลือยังไม่ได้แปล ดูวิธีเพิ่มคำแปลและคำศัพท์ที่ใช้ร่วมกันได้ใน [market/README.md](market/README.md)

## ข้อจำกัดที่ควรรู้

- ทดสอบกับ DSH Web `0.2.1-rc.2`; DSH Desktop ยังไม่ได้ทดสอบติดตั้งจริง
- คีย์ที่ยังไม่มีคำแปลไทยจะแสดงจีนหรืออังกฤษตามระบบ fallback
- ยังไม่มี automated UI test; ตัวตรวจดูรูปแบบไฟล์ ส่วนชุดทดสอบตรวจการทำงานของ client ใน sandbox
- มี 178 รายการที่ควรเปิดดูในบริบทจริง แต่หลายรายการถูกต้องแล้ว
- คำอธิบายปลั๊กอินในตลาดมี 57 รายการจาก 5,324 รายการใน `index.json` ของ awesome-dsh-plugin ณ วันที่รวบรวมข้อมูล ตัวไฟล์ index ไม่ได้เก็บไว้ในรีโป จึงควรตรวจจำนวนนี้ใหม่ก่อนนำไปอ้าง
- สคริปต์ติดตั้ง UI แก้ไฟล์ของปลั๊กอินอื่นในเครื่อง การอัปเดตปลั๊กอินอาจเขียนทับคำแปล ต้องสำรองไฟล์หรือรันสคริปต์ใหม่
- คอมเมนต์ในโค้ดของปลั๊กอินที่แก้ไว้ยังเป็นภาษาจีน แต่ไม่แสดงบนหน้าจอ
