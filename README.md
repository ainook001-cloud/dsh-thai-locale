# DSH ภาษาไทย (dsh-thai-locale)

ปลั๊กอินภาษาไทยสำหรับ **DeepSeek Harness (DSH)** แปลข้อความหน้าจอของ DSH เป็นภาษาไทย และตั้งภาษาเป็นไทยให้เมื่อติดตั้งเสร็จ

## ฟีเจอร์

- แปลข้อความ UI เป็นไทย 4,601 ข้อความ ใน 75 หมวด (namespace)
- ลงทะเบียนภาษา `th` ในรายการภาษาของ DSH
- สลับเป็นภาษาไทยให้หลังติดตั้ง (เปลี่ยนกลับได้ที่ตั้งค่า)
- คีย์ที่ยังไม่มีคําแปลไทยจะแสดงจีนหรืออังกฤษแทน (th → zh → en)
- ไม่ต้องติดตั้ง dependency เพิ่มเติม โค้ดไม่เรียกอินเทอร์เน็ต และไม่บันทึกข้อมูลลงเบราว์เซอร์

## 📋 ข้อกำหนด

| รายการ | รายละเอียด |
|---|---|
| แพลตฟอร์ม | DSH Web — **ทดสอบแล้ว** |
| DSH Desktop | **ยังไม่ได้ทดสอบติดตั้งจริง** — คาดว่าใช้ได้เพราะ Desktop เป็น Electron ที่รัน Web UI ชุดเดียวกัน |
| เวอร์ชัน DSH ที่ทดสอบแล้ว | `0.2.1-rc.2` |
| Node.js | ไม่จำเป็นสำหรับการใช้งาน ใช้เฉพาะตอนตรวจคำแปล |

> `package.json` ประกาศ `dsh.client.platform: "web"` เพราะ client bundle ของ DSH
> ทั้ง Web และ Desktop ใช้ค่าเดียวกันนี้ (Web GUI เป็นตัวเดียวที่โหลด client plugin)
> ค่านี้ไม่ได้แปลว่า "ห้ามใช้บน Desktop" แต่ก็ยังไม่ได้ยืนยันด้วยการติดตั้งจริง

## 🚀 วิธีติดตั้ง

1. เปิดเทอร์มินัลบนเครื่องที่ติดตั้ง DSH และมีคําสั่ง `dsh` ใน PATH
   (คําสั่งนี้เป็นของ CLI ถ้าไม่มี `dsh` ต้องติดตั้ง DSH ก่อน)
2. รันคำสั่งต่อไปนี้

   ```bash
   dsh plugin --profile web add dsh-thai-locale
   ```

3. รอจนติดตั้งเสร็จ แล้วเปิด DSH Web ใหม่

## 📖 วิธีใช้งาน

1. หลังติดตั้ง ภาษาจะเปลี่ยนเป็นไทยอัตโนมัติ
2. ถ้ายังเป็นภาษาอื่น ให้ไปที่ **การตั้งค่า → ภาษา** แล้วเลือก **ไทย**
3. ถ้าพบข้อความที่แปลไม่ถูกต้อง หรือยังเป็นภาษาอังกฤษ ดูวิธีแจ้งในไฟล์ [CONTRIBUTING.md](CONTRIBUTING.md)

## 🔄 เปลี่ยนกลับเป็นภาษาอื่น

ไปที่ **การตั้งค่า → ภาษา** แล้วเลือกภาษาที่ต้องการ หรือถอนปลั๊กอินด้วยคำสั่งถอนของ DSH

## 🌐 สถานะคําแปล

| ส่วน | ที่แปลแล้ว |
|---|---|
| ข้อความ UI ของ DSH | 4,601 ข้อความ / 75 หมวด |
| ชื่อและคําอธิบายปลั๊กอิน | 196 แพ็กเกจ |
| ข้อความในหน้าตั้งค่าปลั๊กอิน | 625 ข้อความ / 9 ปลั๊กอิน |
| พจนานุกรมปลั๊กอินที่ใช้ระบบภาษาเอง | 873 + 188 คีย์ |
| metadata ตลาดปลั๊กอิน | ชื่อตลาด + 23 หมวด + 57 คําอธิบาย |

- แก้อักษรเพี้ยนที่พบชัดเจนแล้ว เช่น อักษรลาวที่หน้าตาคล้ายภาษาไทย เครื่องหมายวรรณยุกต์ซ้ํา คําที่สะกดผิด
- ยังมี 178 รายการที่ตัวตรวจตั้งข้อสงสัยไว้ ดูที่ [TRANSLATION_REVIEW.md](TRANSLATION_REVIEW.md) — หลายรายการถูกต้องอยู่แล้ว
- รีโปนี้ไม่มีไฟล์ภาษาอังกฤษต้นฉบับ จึงยืนยันว่า "แปลครบ 100%" ไม่ได้ ถ้าช่วยตรวจทานยินดีรับ Pull Request

## 🛠 สำหรับผู้พัฒนา

- ไฟล์คำแปลหลักคือ `lib/client.js` ในส่วน `const thDicts = { ... }` จัดกลุ่มตามชื่อ namespace เช่น `"approval": { "waiting": "รอการอนุมัติ" }`
- คงชื่อคีย์และตัวแปรอย่าง `{tokens}` ไว้เหมือนเดิม และห้ามมีอักษรจีนในคำแปล
- ตรวจคำแปลก่อนส่งงานทุกครั้ง

```bash
node --check lib/client.js
node tools/check-translations.mjs   # หรือ npm run check ถ้ามี npm
```

- ถ้าใช้ AI agent ให้อ่าน [AGENTS.md](AGENTS.md) ก่อนแก้ไฟล์

## 🧪 การทดสอบ

```bash
node tools/check-translations.mjs   # ตรวจรูปแบบอักษร
node --test tests/*.test.mjs        # รันโค้ดจริงใน sandbox
```

- ตัวตรวจอักษร: 4,601 คีย์ ต้องได้ข้อผิดพลาด 0
- ชุดทดสอบรัน `lib/client.js` จริง ตรวจการลงทะเบียน 75 namespace, fallback, setLocale และ dispose (6 ข้อ)

รายละเอียดว่าทดสอบอะไรแล้วและอะไรยังขาดอยู่ที่ [docs/testing.md](docs/testing.md)

## 🧩 ชื่อปลั๊กอินไทย (การ์ดปลั๊กอิน)

DSH แสดงชื่อและคำอธิบายปลั๊กอินจากไฟล์ `locale/<รหัสภาษา>.json` ในแพ็กเกจนั้น
แพ็กเกจที่แถมมากับแอปมีแค่ `en` กับ `zh` พอตั้งภาษาเป็นไทยจึงตกไปแสดงภาษาจีน

โปรเจกต์นี้มีคำแปลไทยให้ **196 แพ็กเกจ** — ปลั๊กอินทดลอง 22 ตัวและปลั๊กอินหลักของ DSH อีก 174 ตัว
รวมถึงปลั๊กอินที่ติดตั้งเพิ่มเองอีก 4 ตัว

```bash
node tools/install-plugin-cards.mjs
```

สคริปต์เขียนหรืออัปเดตเฉพาะไฟล์ `locale/th.json` — **ถ้ามีอยู่แล้วจะถูกเขียนทับ** ด้วยเนื้อหาจากรีโปนี้ (ไม่ merge)
ไฟล์ `en.json`, `zh.json` และไฟล์อื่นของแอปไม่ถูกแตะ

## 🔤 ข้อความ UI ในหน้าตั้งค่าของปลั๊กอิน

ปลั๊กอินบางตัวเขียนข้อความหน้าจอเป็นภาษาจีนไว้ในโค้ดเลย ไม่ได้ผ่านระบบภาษา
โปรเจกต์นี้เก็บคำแปลไว้ใน `plugin-locales/ui/<ชื่อปลั๊กอิน>.json` แล้วมีสคริปต์แปะให้

```bash
node tools/install-plugin-ui.mjs
```

| ปลั๊กอิน | ข้อความ |
|---|---|
| `dsh-any-background` | 196 |
| `dsh-opencode-patch` | 116 |
| `dsh-boot-guard` | 70 |
| `dsh-ops` | 52 |
| `dsh-token-saver` | 47 |
| `dsh-plugin-save-token` | 45 |
| `dsh-plugin-guard` | 38 |
| `dsh-plugin-thinking-api` | 38 |
| `dsh-compaction-threshold` | 23 |
| **รวม** | **625** |

⚠️ สคริปต์**เขียนทับไฟล์ client ของปลั๊กอิน** จึงสำรองเป็น `<ไฟล์>.th-bak` ไว้ก่อน
และถ้าอัปเดตปลั๊กอินเหล่านั้น ไฟล์จะกลับไปเป็นจีน ต้องรันสคริปต์ซ้ำ

ปลั๊กอินที่ใช้ระบบพจนานุกรมของตัวเอง (`dsh-our-free-model` 873 คีย์, `dsh-amd-free-model` 188 คีย์)
ได้เพิ่มภาษาไทยเข้าไปในพจนานุกรมแล้ว คำแปลต้นฉบับเก็บไว้ที่ `plugin-locales/dict/`

## 🏪 คำแปลตลาดปลั๊กอิน

ชุดคำแปลสำหรับ **ตลาดปลั๊กอิน DSH** (แคตตาล็อกปลั๊กอิน) แยกไว้ใน `market/`

| ส่วน | สถานะ |
|---|---|
| ชื่อตลาด + คำอธิบายตลาด | ไทยแล้ว |
| ชื่อ **23 หมวด** | ไทยครบ |
| คำอธิบายปลั๊กอิน | **57 รายการ** (agi 45, wsl 12) |
| Node.js | ไม่จําเป็นสําหรับการใช้งาน ใช้เฉพาะตอนตรวจคําแปล |

รายละเอียดวิธีเพิ่มคำแปลทีละหมวดและทะเบียนคำศัพท์อยู่ที่ [market/README.md](market/README.md)

## ⚠️ ข้อจำกัดที่ทราบ

- **ทดสอบบน DSH Web เป็นหลัก** — DSH Desktop ยังไม่ได้ทดสอบติดตั้งจริง
- บางข้อความอาจยังเป็นภาษาอังกฤษหรือจีนเพราะระบบ fallback
- **ยังไม่มี automated UI test** — ตรวจคำแปลได้เฉพาะไวยากรณ์และรูปแบบอักษร (ตัวตรวจใน `tools/`)
- `TRANSLATION_REVIEW.md` ยังมี **178 รายการ** ที่ควรเปิดอ่านในบริบทจริง (หลายรายการถูกต้องแล้ว)
- คําอธิบายปลั๊กอินในตลาดแปลแล้ว **57 รายการ** จากแคตตาล็อกทั้งหมด 5,324 รายการ (ตัวเลข 5,324 มาจาก index.json ของ awesome-dsh-plugin ณ วันที่ดึงข้อมูล — รีโปนี้ไม่เก็บไฟล์นั้น)
- **คําแปลในปลั๊กอินคนอื่นอยู่บนไฟล์ที่ติดตั้ง** — อัปเดตปลั๊กอินแล้วจะถูกทับ ต้องรันสคริปต์ใน `tools/` ซ้ํา
- คอมเมนต์ในโค้ดของปลั๊กอินที่แปลไว้ยังเป็นภาษาจีน (ไม่แสดงบนหน้าจอ)\n
